# PrintKit — Quality in Print. Precision in Design.

This is a **Vite + React** single-page application for PrintKit.

## Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open your browser to view the application.

## Build & Preview

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
